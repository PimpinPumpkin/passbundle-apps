# Word list

`eff-large.txt` is EFF's long word list for passphrases (7,776 words, one per
line), from https://www.eff.org/dice, by the Electronic Frontier Foundation,
used under the Creative Commons Attribution 3.0 United States license
(https://creativecommons.org/licenses/by/3.0/us/). The words are unchanged;
the dice numbers are left out.
